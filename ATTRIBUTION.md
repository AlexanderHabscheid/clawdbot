## What We Changed

Centris extends OpenClaw with:

- Voice-first computer automation (desktop control, browser automation)
- Deepgram voice pipeline integration
- Chrome extension bridge for browser control
- Multi-agent orchestration with specialized agents (browser, system, file, planning)
- Connector framework and SDK for third-party app integration
- Native iOS, Android, and macOS apps
