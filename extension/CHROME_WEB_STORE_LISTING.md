## Store Listing Justifications (for review)

### Why <all_urls> permission?

Centris is a browser automation tool that controls any website the user visits. Users say commands like "go to Gmail" or "open Slack" and Centris navigates and interacts with those pages. This requires access to all URLs to provide a seamless experience across any website.

### Why nativeMessaging permission?

The extension communicates with the Centris desktop app, which captures voice input and processes AI commands. Native messaging enables fast, secure communication between the extension and the desktop app.

### Why scripting permission?

Centris needs to inject content scripts to interact with page elements (clicking buttons, filling forms, reading content). This is the core functionality that enables browser automation.

### Why tabs permission?

Centris needs to know which tab is active to execute commands in the correct context. This enables commands like "open a new tab" or "go back to the previous tab".
